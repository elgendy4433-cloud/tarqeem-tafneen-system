# دليل رفع المنصة السحابي الفوري (خلال 30 ثانية مجاناً)

تم تجهيز حزمة النشر السحابي داخل مجلد:  
`d:\مشروع ترقيم وتفنين\dist\`

---

## 🚀 الخيار الأول (الأسرع والأسهل - بنقرة وسحب): عبر Netlify Drop

1. اضغط مرتين على الملف:
   👉 **`deploy_online.bat`**  
   *(سيفتح لك المتصفح على صفحة الرفع ويفتح مجلد `dist` تلقائياً)*.

2. أو افتح الرابط يدوياً في المتصفح:  
   🔗 **[https://app.netlify.com/drop](https://app.netlify.com/drop)**

3. **اسحب مجلد `dist`** وأفلته داخل دائرة الرفع في الموقع.

4. **مبروك! 🎉**  
   ستحصل فوراً على رابط دائم ومحمي بشهادة أمان SSL مجاناً مثل:  
   `https://tarqeem-tafneen.netlify.app`  
   *(يمكنك تغيير اسم الرابط إلى أي اسم تريده من إعدادات Site settings > Change site name)*.

---

## ⚡ الخيار الثاني: عبر Vercel

1. اذهب إلى **[https://vercel.com/new](https://vercel.com/new)**.
2. اسحب مجلد `dist` أو ارفع الملفات.
3. اضغط **Deploy**.
4. ستحصل فوراً على رابط مثل:  
   `https://tarqeem-tafneen.vercel.app`

---

## 🌐 الخيار الثالث: عبر Tiiny Host (بدون تسجيل)

1. افتح **[https://tiiny.host](https://tiiny.host)**.
2. اكتب الاسم الذي تريده لرابطك (مثلاً: `tarqeem`).
3. اسحب ملف `index.html` الموجود داخل `dist`.
4. اضغط **Publish** وستحصل على الرابط فوراً!

---

## 📱 مميزات الرابط بعد الرفع:
- يعمل على الهواتف الذكية (آيفون، أندرويد)، الأجهزة اللوحية (iPad)، وأي كمبيوتر.
- سريع جداً وآمن مشفر بـ HTTPS.
- لا يتطلب أي سيرفر أو تكاليف استضافة شهرية.
- يدعم استيراد وتصدير الإكسل وحفظ البيانات ومحاكاة التنبيهات على كل الأجهزة.
