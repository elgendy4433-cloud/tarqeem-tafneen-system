# نظام المتابعة (ترقيم & تفنين)

نظام متكامل مبني لإدارة ومتابعة الوثائق الرسمية، الإقامات، والعقود الوظيفية لكل من **مؤسسة ترقيم (TRQEM)** و**شركة تفنين (TAFNEEN)** بالهوية الرسمية المعتمدة لكلا الكيانين وبحساب موحد مع عزل كامل للبيانات، والتخلص النهائي من أخطاء الإكسل الحسابية عبر احتساب الحالات ديناميكياً وجدولة تنبيهات فورية عبر البريد الإلكتروني.

## 🌟 مميزات النظام

1. **المصادقة وحارس التوجيه (Auth Gate & Route Guard)**:
   - منع الوصول غير المصرح به لواجهة النظام أو بيانات المؤسستين تلقائياً.
   - تسجيل دخول آمن عبر البريد الإلكتروني وكلمة المرور مدعوم عبر Supabase Auth.
   - دعم استرجاع كلمات المرور عبر البريد الإلكتروني.
   - أزرار تجربة سريعة للأدوار المختلفة (مدير ترقيم، مشرف تفنين، إدارة مشتركة، مستعرض تقارير).

2. **شاشة اختيار المنشأة والعزل الصارم (Strict Multi-Tenancy)**:
   - بعد تسجيل الدخول تظهر شاشة لاختيار المنشأة، وتعرض **فقط** المنشآت المصرح بها للمستخدم:
     - مستخدم ترقيم فقط: محجوب تماماً عن بيانات تفنين.
     - مستخدم تفنين فقط: محجوب تماماً عن بيانات ترقيم.
     - المستخدم المشترك: يحدد السياق بوضوح وبإمكانه التبديل بينهما مع إعادة التحقق من الأذونات فوراً.
   - تطبيق سياسات أمان مستوى الصفوف (Row Level Security - RLS) ودوال `has_org_access` على مستوى قاعدة بيانات PostgreSQL.

3. **لوحة إدارة المنشأة وسجل التدقيق الأمني (Admin & Audit Logging)**:
   - دعوة أعضاء جدد وتحديد أدوارهم وصلاحياتهم (Admin, Manager, User).
   - تفعيل أو تعليق العضويات (`active` / `suspended`) فورياً.
   - سجل تدقيق أمني مباشر وغير قابل للتعديل يتتبع كافة العمليات الحساسة (تسجيل الدخول، تبديل المنشأة، الإضافة، التعديل، الحذف، تعديل الصلاحيات) مع إمكانية التصدير إلى Excel.

4. **دعم الوضعين الليلي والنهاري (Dark & Light Mode Switch)**:
   - سوتش فوري في أعلى المنصة للتبديل بين الوضع الليلي والوضع النهاري بضغطة زر.
   - مواءمة بصرية متقنة لألوان وهوية كل من مؤسسة ترقيم وشركة تفنين في كلا الوضعين.
   - حفظ تفضيل المستخدم في التخزين المحلي (`localStorage`).

5. **رسم بياني بمؤشرات متناسقة بلونين فقط**:
   - تم تبسيط وتنسيق الرسم البياني ليعتمد على **لونيْن منسجمين فقط** يمثلان هوية الكيان:
     - **اللون الأول**: سجلات سارية ومستقرة.
     - **اللون الثاني**: سجلات تتطلب اتخاذ إجراء (قريب الانتهاء + منتهي).
   - عرض تفصيلي مباشر عند تمرير الماوس (Tooltip) يوضح عدد السجلات المنتهية وتلك القريبة من الانتهاء بدقة.

6. **الوحدات الثلاث الرئيسية**:
   - **وحدة الإقامات**: الاسم، رقم الإقامة، المهنة، الفرع، تاريخ الانتهاء، الأيام المتبقية، الحالة، ملاحظات، ملاحظات النقل والتجديد.
   - **وحدة العقود الوظيفية**: الاسم، رقم الهوية/الإقامة، المهنة، تصنيف المهارات، الإدارة، بداية العلاقة التعاقدية، بداية ونهاية العقد، عدد مرات التجديد، الحالة، الملاحظات. (حل مشكلة `#VALUE!` نهائياً).
   - **وحدة التراخيص والشهادات**: اسم الوثيقة، النوع، الرقم، الفرع، تاريخ الإصدار، تاريخ الانتهاء، الحالة، الملاحظات.

7. **محرك الاستيراد من Excel الذكي**:
   - معالجة التواريخ الرقمية المشفرة في إكسل (مثل `46438`) وتحويلها إلى تواريخ ميلادية صحيحة.
   - التحديث التلقائي الذكي (Upsert): تحديث السجل عند تكرار رقم الإقامة أو رقم الهوية أو رقم الترخيص بدلاً من رفضه أو تكراره.
   - تقرير فوري بالأخطاء والصفوف غير الصالحة.
   - تنزيل قوالب Excel فارغة جاهزة للاستخدام بنقرة واحدة.

8. **نظام التنبيهات الفورية وإرسال البريد الإلكتروني (Email Delivery & Alerts)**:
   - نظام متكامل لإرسال التنبيهات والتقارير عبر **٥ طرق مختلفة**: عميل البريد المكتبي (Mailto)، خدمة EmailJS السحابية المباشرة، Resend API، روابط Webhook، وخادم SMTP المحلي في Laravel.
   - شارة حالة البريد في الشريط العلوي (`MAIL: ON 🟢`).
   - نافذة منبثقة تفاعلية لمعاينة شكل تقرير البريد (HTML Preview) وإرساله للمسؤولين بنقرة واحدة.
   - زر إرسال بريد تجريبي (Test Email) للتحقق من الاتصال وسلامة الإعدادات.
   - فحص دوري ذكي لأي إقامة بقي عليها **٤٥ يوماً أو أقل**، وأي عقد وظيفي بقي عليه **٩٠ يوماً أو أقل**، وأي ترخيص بقي عليه **٦٠ يوماً أو أقل**.
   - توثيق كافة حركات إرسال البريد آلياً في سجل التدقيق الأمني (Audit Logs).
   - دليل التشغيل الكامل متوفر في: [`EMAIL_SETUP_GUIDE.md`](file:///d:/مشروع%20ترقيم%20وتفنين/EMAIL_SETUP_GUIDE.md).

9. **حزمة الفحوصات والاختبارات الآلية (Automated E2E Suite)**:
   - زر فحص آلي مدمج في واجهة النظام ينفذ كافة الاختبارات ويعرض بطاقات التحقق مباشرة.
   - ملف اختبارات Node.js مستقل: [`tests/platform_e2e_tests.js`](file:///d:/مشروع%20ترقيم%20وتفنين/tests/platform_e2e_tests.js).

## 🚀 متطلبات التشغيل والتثبيت

- **PHP**: الإصدار 8.2 أو أحدث (مع تفعيل إضافات: `pdo_mysql`, `mbstring`, `gd`, `zip`, `xml`).
- **قاعدة البيانات**: MySQL أو MariaDB.
- **Composer**: مثبت في النظام.

### خطوات التشغيل:

1. **تثبيت الحزم**:
   ```bash
   composer install
   ```

2. **إعداد قاعدة البيانات (PostgreSQL / Supabase)**:
   - يتم ضبط بيانات الاتصال السحابي عبر المتغيرات البيئية داخل ملف `.env`:
     ```env
     SUPABASE_URL=https://your-project.supabase.co
     SUPABASE_ANON_KEY=your_public_anon_key
     DATABASE_URL=postgresql://user:password@host:5432/database?sslmode=require
     ```
   - مخطط SQL الكامل وسياسات أمان الصفوف متوفرة في: [`supabase/migrations/20261029_initial_schema.sql`](file:///d:/مشروع%20ترقيم%20وتفنين/supabase/migrations/20261029_initial_schema.sql)

3. **تشغيل الهجرات والبذور (Migrations & Seeders)**:
   ```bash
   php artisan migrate --seed
   ```
   *سيقوم هذا الأمر بتهيئة الجداول وإنشاء مؤسسة (ترقيم) وشركة (تفنين) والمستخدم الافتراضي: `admin@tarqeem.com` وكلمة المرور: `admin123456`.*

4. **تشغيل خادم التطوير**:
   ```bash
   php artisan serve
   ```
   افتح المتصفح على: `http://localhost:8000`

5. **تشغيل فحص التنبيهات يدوياً في أي وقت**:
   ```bash
   php artisan alerts:send
   ```
   *أو عبر زر "فحص التنبيهات الآن" في لوحة التحكم.*
