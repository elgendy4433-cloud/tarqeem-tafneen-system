# نظام المتابعة (ترقيم & تفنين)

نظام متكامل مبني لإدارة ومتابعة الوثائق الرسمية، الإقامات، والعقود الوظيفية لكل من **مؤسسة ترقيم (TRQEM)** و**مؤسسة تفنين (TAFNEEN)** بالهوية الرسمية المعتمدة لكلا الكيانين وبحساب موحد مع عزل كامل للبيانات، والتخلص النهائي من أخطاء الإكسل الحسابية عبر احتساب الحالات ديناميكياً وجدولة تنبيهات فورية عبر البريد الإلكتروني.

## 🌟 مميزات النظام

1. **دعم الوضعين الليلي والنهاري (Dark & Light Mode Switch)**:
   - سوتش فوري في أعلى المنصة للتبديل بين الوضع الليلي والوضع النهاري بضغطة زر.
   - مواءمة بصرية متقنة لألوان وهوية كل من مؤسسة ترقيم ومؤسسة تفنين في كلا الوضعين.
   - حفظ تفضيل المستخدم في التخزين المحلي (`localStorage`).

2. **رسم بياني بمؤشرات متناسقة بلونين فقط**:
   - تم تبسيط وتنسيق الرسم البياني ليعتمد على **لونيْن منسجمين فقط** يمثلان هوية الكيان:
     - **اللون الأول**: سجلات سارية ومستقرة.
     - **اللون الثاني**: سجلات تتطلب اتخاذ إجراء (قريب الانتهاء + منتهي).
   - عرض تفصيلي مباشر عند تمرير الماوس (Tooltip) يوضح عدد السجلات المنتهية وتلك القريبة من الانتهاء بدقة.

3. **دعم تعدد المؤسسات (Multi-Tenancy)**:
   - التبديل الفوري بين مؤسسة **ترقيم** ومؤسسة **تفنين** من القائمة العلوية.
   - عزل كامل للبيانات والسجلات لكل مؤسسة تلقائياً.

4. **الوحدات الثلاث الرئيسية**:
   - **وحدة الإقامات**: الاسم، رقم الإقامة، المهنة، الفرع، تاريخ الانتهاء، الأيام المتبقية، الحالة، ملاحظات، ملاحظات النقل والتجديد.
   - **وحدة العقود الوظيفية**: الاسم، رقم الهوية/الإقامة، المهنة، تصنيف المهارات، الإدارة، بداية العلاقة التعاقدية، بداية ونهاية العقد، عدد مرات التجديد، الحالة، الملاحظات. (حل مشكلة `#VALUE!` نهائياً).
   - **وحدة التراخيص والشهادات**: اسم الوثيقة، النوع، الرقم، الفرع، تاريخ الإصدار، تاريخ الانتهاء، الحالة، الملاحظات.

5. **محرك الاستيراد من Excel الذكي**:
   - معالجة التواريخ الرقمية المشفرة في إكسل (مثل `46438`) وتحويلها إلى تواريخ ميلادية صحيحة.
   - التحديث التلقائي الذكي (Upsert): تحديث السجل عند تكرار رقم الإقامة أو رقم الهوية أو رقم الترخيص بدلاً من رفضه أو تكراره.
   - تقرير فوري بالأخطاء والصفوف غير الصالحة.
   - تنزيل قوالب Excel فارغة جاهزة للاستخدام بنقرة واحدة.

6. **نظام التنبيهات الفورية (Email Alerts)**:
   - فحص دوري يومي عند الساعة 8:00 صباحاً.
   - تنبيه فوري لأي إقامة بقي عليها **٤٥ يوماً أو أقل**.
   - تنبيه فوري لأي عقد وظيفي بقي عليه **٩٠ يوماً أو أقل**.
   - إرسال التنبيه مرة واحدة فقط لكل دورة تجديد لمنع إزعاج المسؤولين.
   - إمكانية تعديل عتبات الأيام (45 و 90) وقوائم البريد من لوحة التحكم.

## 🚀 متطلبات التشغيل والتثبيت

- **PHP**: الإصدار 8.2 أو أحدث (مع تفعيل إضافات: `pdo_mysql`, `mbstring`, `gd`, `zip`, `xml`).
- **قاعدة البيانات**: MySQL أو MariaDB.
- **Composer**: مثبت في النظام.

### خطوات التشغيل:

1. **تثبيت الحزم**:
   ```bash
   composer install
   ```

2. **إعداد قاعدة البيانات (Neon Serverless PostgreSQL - مربوطة سحابياً)**:
   - تم ربط المشروع رسمياً بقاعدة بيانات **Neon** السحابية على خادم AWS US East 2.
   - بيانات الاتصال مفعلة ومضبوطة داخل ملف `.env`:
     ```env
     DB_CONNECTION=pgsql
     DB_HOST=ep-old-sky-b4emfege-pooler.c-6.us-east-2.aws.neon.tech
     DB_PORT=5432
     DB_DATABASE=neondb
     DB_USERNAME=neondb_owner
     DB_PASSWORD=npg_cM95XCAElyGn
     DB_SSLMODE=require
     DATABASE_URL="postgresql://neondb_owner:npg_cM95XCAElyGn@ep-old-sky-b4emfege-pooler.c-6.us-east-2.aws.neon.tech/neondb?sslmode=require&channel_binding=require"
     ```

3. **تشغيل الهجرات والبذور (Migrations & Seeders)**:
   ```bash
   php artisan migrate --seed
   ```
   *سيقوم هذا الأمر بتهيئة الجداول وإنشاء مؤسستي (ترقيم) و(تفنين) والمستخدم الافتراضي: `admin@tarqeem.com` وكلمة المرور: `admin123456`.*

4. **تشغيل خادم التطوير**:
   ```bash
   php artisan serve
   ```
   افتح المتصفح على: `http://localhost:8000`

5. **تشغيل فحص التنبيهات يدوياً في أي وقت**:
   ```bash
   php artisan alerts:send
   ```
   *أو عبر زر "فحص التنبيهات الآن" في لوحة التحكم.*
